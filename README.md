# DOT311 — Hafta 2: JavaScript (ES6+) Temelleri ve Liste İşleme

Bu proje, React Native'de sıkça kullanılan Modern JavaScript (ES6+) yapılarını, dizi metotlarını (`map`, `filter`, `reduce`), template literal'leri ve destructuring kullanımını içerir.

## İçerik
1. **`js-alistirmalari.js`**: 2. Hafta ders notu Bölüm 9'da verilen 3 alıştırmanın (map, filter, forEach + template literal) Node.js çözümü.
   - Çalıştırmak için:
     ```bash
     node js-alistirmalari.js
     ```
2. **`App.js`**: React Native arayüzünde dinamik skor tablosu ve envanter filtreleme ekranı.

## WebStorm'da Çalıştırma ve Expo Go Testi
1. WebStorm'da bu klasörü açın.
2. Terminalden uygulamayı başlatın:
   ```bash
   npx expo start
   ```
3. Telefonunuzdaki **Expo Go** uygulaması ile QR kodu tarayın.
